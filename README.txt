This is a clean, responsive portfolio with a scenic hero background image and the resume PDF included.

To preview: open index.html in a browser.

To update your existing GitHub Pages repository:
1. Extract this ZIP on your computer.
2. Open the extracted folder.
3. In GitHub, open your existing repository > Add file > Upload files.
4. Upload index.html, style.css, script.js and the entire assets folder.
   Tip: open the assets folder and select both files, then drag those files into GitHub's upload area. This avoids the folder-upload issue.
5. Commit changes. Keep the assets directory structure exactly as provided.
6. Wait for GitHub Pages to deploy, then refresh your existing site URL.
